# 🏥 EthioCare — Smart Hospital & Patient Services

EthioCare is a Python-based hospital management system designed to make healthcare services easier and more accessible. It allows patients, doctors, hospitals, and administrators to manage important healthcare services through a simple desktop application.

## ✨ Main Features

* 👤 Patient Registration & Login
* 📅 Appointment Booking
* 👨‍⚕️ Doctor Registration & Login
* 🏥 Hospital Registration
* ✅ Hospital Approval & Rejection by Admin
* 📋 Doctor Appointment Management
* 💳 Online Payment Management
* 👨‍⚕️ Available Doctors
* 📜 Previous Hospital Achievements
* 🚨 Emergency Contacts
* 🌙 Dark & Light Mode
* 🌍 Multi-language Support
* 📱 Responsive & Scrollable Interface
* 🔐 Admin Management

## 🛠️ Technologies Used

* **Python**
* **Tkinter** — Graphical User Interface
* **SQLite** — Local database
* **Hashlib** — Password security
* **Datetime** — Appointment and payment records

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

2. Open the project folder in **VS Code** or **PyCharm**.

3. Run:

```bash
python EthioCare.py
```

The SQLite database will be created automatically when the application starts.
